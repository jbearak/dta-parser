# Issue 216 research records

These records support [the read_dta construction and deferred-decoding research note](../read-dta-construction-and-deferred-decoding.md). The note contains the findings and recommendation. This bundle preserves the code, source identities, commands, raw observations, calculations and review records needed to inspect those findings.

The experiments used production baseline de83bcbbeca9771dacf6e91fe727d2a228172d64, package tree a7ca8e846439a44170ccb1023aa73a58818cff73. The eager phase diagnostic was a separate private build at 2fa68af1f1d6efad61c9f5c31c7e104744c020ae. The numeric snapshot experiment was the explicitly modified private build `issue216-numeric-snapshot-source04-de83-8bc09dba`. Neither private build is a production change or an ordinary-baseline installation. User PR219 subsequently changed package metadata/tests on main; final production acceptance must bind the actual research merge separately, without relabeling these measurements.

`selection.json` maps every original path to a canonical archive member, with regular-file mode, size and SHA-256 digest. Members use `records/<original absolute path relative to /private/tmp>`. For example, the recorded question is `records/dta-direct-issue216-preparation-01/issue.json`. Original preparation and validation directory names remain intact. The archive README and replay guide are external sidecars, so the final archive digest can be recorded without self-reference.

The selected records include project-owned R/Python/Rust/C/Stata helpers and prototype patches, owned-input generators and schema inventories, exact source/install/clock identities, source-bound configs and child outcomes, timing/sequence/allocation/heap/RSS observations, native phase traces, plain numeric-counter exports, calculations and independent reviews. Pilots and functional qualifications remain separate from accepted observations. The selection also preserves failed installs, unsuccessful signal witnesses, the combined native retry's exit-one reentry result, the restricted time-wrapper failure, and corrected saved-data/reconstruction checks.

The main accepted load matrix has 1,329 children and 2,016 accepted observations. Current/direct workflows have 284 children and 512 accepted observations; their memory/sequence set has 400 jobs. The numeric matrix has 846 children and 1,408 accepted observations across 176 groups, followed by 450 memory/sequence jobs. Its plain export covers 8,824 Stats records and 722,639 source-column rows. These counts identify distinct data sets, not pooled replications. Native phase sampling has 49 method processes with two warmups and seven measured single reads per method. Its GC-preceded, instrumented regime is separate from amortized load timing.

Four structured timeout/cancellation records are published as separately named metadata derivatives. Their original Python traceback strings contained short standard-library source excerpts. The derivatives preserve frame paths/line numbers, task-owned frame text, exception outcomes and all unrelated JSON fields, while omitting those external source/caret lines. The derivation record binds the original hashes and exact replacements; original records remain local.

Three installation records likewise use metadata derivatives. They retain the captured runtime, library/DLL, package version/build/license and private-signature facts while omitting full dependency descriptions. The seven original-to-derivative mappings are in `publication-replacements.json`; omission sidecars retain field names and digests without their removed contents.

The bundle excludes generated DTA files and broad serialized R object graphs, other-repository code/data, dependency source/install trees or build archives, compiled libraries and executables, raw compiler/test consoles, and Stata startup/help/license/raw-log content. Stata's task-written timing/runtime TSVs retain version and processor-capacity metadata used to interpret the measurements. Paths and hashes referring to excluded inputs are provenance references; they do not imply that those bytes are bundled. Governing project LICENSE/NOTICE texts accompany the selected project patches and helpers.

Read `REPLAY.md` for source reconstruction and record inspection. Re-execution requires public pinned Git source, the recorded R/dependency/toolchain environment, and separately licensed Stata. The bundle does not reproduce a complete operating-system image or promise identical timings on another host. The report records cold-cache limits, single-host scope, observer costs, source-lifetime cases and unsupported prototype cases.

Final archive identity and selection totals are recorded in `transport-result.json` and the external publication metadata. Content-origin and archive-member checks are recorded separately. Use their stated scope and the transport result to assess the published artifact; this README is not a workload execution record.
