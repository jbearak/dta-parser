# Inspecting and reconstructing the experiments

Start with `selection.json` and `transport-result.json`. Verify the compressed archive SHA-256 from the transport record, then verify each selected member's path, regular-file type, mode, size and digest. The publication transport retained that complete roundtrip. Use the original member names from the manifest; no automatic extraction or producer execution is needed to inspect a table.

All member paths below begin with `records/`. `P/` abbreviates `dta-direct-issue216-preparation-01/`, and `V/` abbreviates `dta-direct-issue216-validation/`. These abbreviations are navigation only, not extra archive directories. Referenced absolute paths in historical records remain their original paths.

Use `P/evidence-selection-preparation-01/publication-replacements.json` for all seven original-to-derivative mappings. The four traceback records have detailed checks in `P/evidence-selection-preparation-01/traceback-metadata-01/derivation-result.json`; the three installation records have whitelist/omission details under `P/evidence-selection-preparation-01/installed-metadata-02/records/`. The original record hashes map to separately selected derivative members. Frame metadata and outcomes remain intact, while external standard-library source excerpts are excluded. A historical reference to the original digest remains a reference to excluded original bytes, not the derivative digest.

Use the selected assessor source that is named by each result or review. These data readers recompute aggregates from saved observations. They do not need a fresh reader benchmark. Keep pilot/final labels, timing batch divisors, warmup rows, method capture flags and GC boundaries intact. Unavailable private counters mean no instrumented snapshot at that checkpoint, not zero eager work. An after-batch counter describes the final call only; before and after separate reads cannot be subtracted as if they were the same snapshot. Native-detail policy labels are not proof that baseline or R-wrapper methods captured a trace.

For source reconstruction, check out public commit de83bcbbeca9771dacf6e91fe727d2a228172d64 into separate clean directories. Apply `P/numeric-prototype-source-04/prototype.patch` for the accepted numeric experiment. Apply `P/source-reconstruction-01/eager-source03-reconstruction.patch` for the accepted eager diagnostic. `git apply` can apply both canonical full patches from the repository root. Compare the resulting changed-file sizes, modes and SHA-256 values with the corresponding source freeze and accepted build manifest before compiling anything.

The numeric patch reproduces seven changed files. The canonical eager patch reproduces five changed files and matches actual install revision 2fa68af1, including its cfg(test) block. The historical eager source01-to02 patch mixes basename/preparation paths, and its source02-to03 patch encodes the actual appended test block as a beginning-of-file insertion. Those historical artifacts and the failed literal replay are retained as provenance. Use the additive canonical full patch for a direct replay. Earlier failed numeric build versions are historical identity/outcome records; their complete reconstruction is not claimed from the final source04 patch.

To regenerate owned inputs, use `P/harness-source-01/fixture-generator-draft-01.R` for the 28 main cases and `P/prototype-controls-preparation-01/pure-numeric-fixtures.R` for the five-width cases. Compare the resulting shape/schema inventory with `V/fixtures-01/payload/{fixtures.csv,column-schemas.csv}` and `V/pure-numeric-fixtures-01/payload/{fixtures.csv,schemas.csv}`. A new writer/toolchain may change file bytes or timestamps, so bind newly generated inputs and requalify their correctness before treating them as a new measurement set. The excluded original DTA/RDS data is not silently available through an inventory hash.

A fresh experiment run must adapt the selected paths to a new isolated workspace and record the actual source/install/configuration identities. Historical launch configs intentionally bind the original exact paths and bytes and will reject an unrelated installation. Use the actual frozen harness generation named by that run; generations01-05 are distinct. The high-resolution clock has its own selected C source, build/check configs and successful observations. The shared-library payload is excluded and must be rebuilt and checked locally. Install ordinary baseline and each private research build separately, using their accepted validator conventions. Do not label a modified prototype with the ordinary baseline commit alone.

Run functional controls before collecting new estimates. Preserve actual SIGINT/fork/collection outcomes, failed witness attempts and recovery assertions. A controller timeout or a signal outside native execution is not a native cancellation witness. Keep performance windows quiet and retain primary observations and failures. Stata calls require the reader's own licensed installation; the original binary, license and startup outputs are not distributed here. Any new experiment result is a new run with new identities, not a replayed acceptance claim for the historical measurements.
