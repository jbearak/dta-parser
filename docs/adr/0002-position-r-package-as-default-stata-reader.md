# Position the R package as the default Stata reader

The R package will present itself as the default choice for importing Stata DTA files, based on its broad performance results and haven-compatible read contract. It is not a haven replacement: projects may continue to use haven for writing files, other statistical formats, or related helpers. Read-only support describes the package today but is not a permanent scope boundary; future work will follow the needs of Stata users rather than seek haven feature parity for its own sake.
