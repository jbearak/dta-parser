# Give `gen()` and a new `:=` column Stata's `generate` default

`gen()` and `data[i, y := value]` on a column that does not exist are translations of Stata's `generate`, and a bare double result now takes that command's default storage: `float`, or `double` when `options(dtatools.generate_type = "double")` is set, the equivalent of Stata's `set type double`. A result that already carries storage keeps it, whether from a `dta_*()` constructor or from arithmetic on a typed column, which declares storage through the Stata lattice as everywhere else; the default reaches a bare double such as a literal, `NA_real_`, or the result of a base function that drops the class. Bare integer results stay `long`, and every other way a column enters a dibble, including `dibble()`, `as_dibble()`, `mutate()`, `transform()`, and the replacement operators, keeps the lossless mapping of ADR 0021. Overwriting an existing column through `:=` promotes from the column's storage as before.

ADR 0021 gave every entry point one lossless mapping, so `gen(data, y = x * 2)` stored a `double` where Stata's `generate y = x * 2` stores a `float`. Translating a Stata script then meant wrapping every untyped `generate` in `dta_float()` to keep the storage the original produced: a first project had about 29 such lines, each restating a default that belongs to the command. The alternative kept was to distinguish a Stata command from an R container operation: `gen()` and a new `:=` column emulate `generate` and follow its default, while `mutate()` and the operators are R operations on the container and follow R's types. The same expression can therefore take `float` through `gen()` and `double` through `mutate()`; the `stata-storage-defaults` page states both rules. `dta_double()` remains the explicit `generate double`. Integers were not sent to `float` because an R integer comes from R rather than from a translated Stata line, and `float` loses integers above 2^24. Making the default an option rather than a `gen()` argument mirrors `set type`, which is a session setting in Stata, and keeps translated lines free of it.
