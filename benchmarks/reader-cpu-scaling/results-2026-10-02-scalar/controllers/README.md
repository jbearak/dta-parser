# Scalar benchmark rerun sources

`scalar-worker.R` and `scalar-access-probe.c` are the measured source bytes. The benchmark controllers, probe check and regression wrappers are templates with local path literals replaced by environment variables. The copied build recorder also replaces one path in its documentation example; its logic is unchanged. The transformed copies were not executed unchanged. Original and published hashes, plus the transformation type, are recorded in `../publication-source-map.json`; measured hashes remain in each stage's provenance.

Set `DTATOOLS_SCALAR_WORK` to a private work directory, `DTATOOLS_REPO` to this repository, `DTATOOLS_DECODE_WORK` to the earlier decode experiment directory containing `candidate-gather4-v2`, and `DTATOOLS_SCALAR_FIXTURES` to the compact fixture directory. The optional focused regression wrapper also uses `DTATOOLS_COMPARATOR_LIBRARY` for installed test dependencies. Copy the controller, worker, probe source and check script into the scalar work directory under their original filenames.

The controller requires source-bound candidate build directories for each configured role. Each contains `build-receipt.json`, `input-record.json`, `source.patch`, the frozen `source/` tree and installed `library/dtatools/` tree. The initial screen maps current to the earlier gather4-v2 build, sourcecheck to `candidate-sourcecheck`, dispatch to `candidate-dispatch-v2`, and reverse to `candidate-reverse`. Dispatch v1 is an unmeasured diagnostic. The separately preserved `scalar-acceptance.py` adds accepted as `candidate-combined`; the screen controller remains unchanged.

The compact fixtures are `compact.dta`, `compact.arrow` and `compact.rds`, generated by the earlier file-reader fixture script. Qualification requires the same shapes, names and selected compact columns in both formats and the ordinary RDS reference. Input hashes are preserved in provenance. No binary fixture or installed library is published here.

Build the probe with `R CMD SHLIB scalar-access-probe.c -o scalar_access_probe.so`, using the flags in the probe build receipt, then run the untimed probe check. Regenerate the receipt/check records with your own paths and hashes; copying the historical receipts would fail the controller's source and binary binding checks. Preserve the existing recorder/helper/runtime files at `benchmarks/r-file-readers/` in the repository; their measured copies are included here under `r-file-readers/` for audit.

Run the initial screen from the scalar work directory with `python3 scalar-benchmark.py --work screen --variants current,sourcecheck,dispatch,reverse --cases screen --rounds 4 --reps 4`. Each setting uses a fresh R process. The controller binds input, package, runtime and probe bytes before and after, and validates results outside the operation timer. The operation interval includes all configured repetitions and automatic garbage collection. Reported per-scan/per-value metrics divide this interval by the actual recorded repetitions and row count.

The independent scalar acceptance command is `python3 scalar-acceptance.py --work acceptance --variants current,accepted --cases '*-proxy-*' --rounds 6 --reps 8`. This includes twenty cases, adding integer and long masks to the screen cases, for 240 observations.

Reader controls use the existing `benchmarks/r-file-readers/run.py` with the current and accepted libraries, a local copy of the fixture manifest containing your actual input paths, and the combined build-binding record. The measured options are `--methods dtatools_dta_dibble dtatools_arrow_dibble --cases compact numeric mixed wide --threads 0 --modes read consume --pairs 6`, producing 192 observations. The required path options are `--baseline`, `--candidate`, `--fixtures`, `--work`, and `--build-record`. These are separate read-return and full-consumption processes; they should not be interpreted as scalar-scan intervals.

All source copies and records are intended to make the experiment auditable. These instructions do not claim a clean-machine rebuild or a rerun of the transformed templates was tested.
