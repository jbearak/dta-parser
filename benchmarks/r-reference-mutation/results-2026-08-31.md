Compact position selectors stayed in native storage when paired with
full-dataset values. Replacement made no R allocation above the profiler's
1,000-byte threshold. Generation allocated its required 20,000,048-byte
long payload once and no double index.

An ordinary double target gathered one selected value from a five-million-row
source before casting. It allocated 18,824 profiled bytes in total, down from a
full-dataset temporary, and its largest allocation was 4,760 bytes.

Compact float generation completed in 0.069 seconds against 0.071 seconds for
direct `stata_float()` construction, confirming validation and encoding share
one pass. Scalar character generation allocated one 40,000,048-byte result
header and finished in 0.017 seconds. Full-vector generation took 0.037 seconds
against a 0.0134-second independent vector-copy baseline; sparse generation took 0.011
seconds. Each allocated only its required result. These cases confirm that
width inference neither traverses full replacement values twice nor rescans a
five-million-row sparse result. POSIXct generation stayed within 13,544 bytes
of its required double result.

The shared high-cardinality dictionary overwrite allocated one character result
and finished in 0.021 seconds without decoding the old payload or duplicating
the output. Full generation from that dictionary source took 0.061 seconds;
full replacement took 0.105 seconds against a 0.066-second ordinary-source
baseline. Both used a two-megabyte private cache and left the shared source
cache unchanged. Replacing one row allocated no R object above the profiler's
1,000-byte threshold. Generic
ALTREP replacement allocated one ordinary 20,000,048-byte integer vector and
took 0.009 seconds. Its sparse counterpart
took 0.020 seconds with the same single-vector allocation; dataset aliases
observed both results, and source column aliases remained unmodified sequences.
Package-owned existing columns kept their original `tracemem()` addresses.
