# Numeric and expression performance — 2026-09-29

The extracted optimizations improve all 36 measured dibble operation/shape/storage combinations over merged main: median speedups range from 1.06× to 5.38×. They do **not** establish the requested dplyr/data.table parity. Only one of those 36 candidate medians beats plain dplyr, and none is within ±5% of plain data.table. These are descriptive sample medians, not a claim of statistical equivalence or coverage of every public operation.

This report measures the installed performance branch. The earlier PR #265 table measured the correctness changes alone. Earlier near-parity results from isolated whole-operation prototypes are not measurements of this branch; their remaining callback, lifetime and publication work is not included here.

All dtatools operations below run on **dibbles**. The two modes refer to their input column storage: ordinary R double buffers with Stata attributes, or package-owned double buffers. Compact numeric payloads are excluded. The comparators are dplyr on ordinary tibbles and data.table on ordinary data.tables, both with plain double columns.

## Public comparisons

- R 4.6.1 (revision 90187), macOS ARM64; dplyr 1.2.1, data.table 1.18.6.1, vctrs 0.7.3, rlang 1.3.0. These versions exercise the supported native execution profiles. Other profiles retain the R fallbacks.
- Four separate R processes, in main–candidate–candidate–main order, with seeds 265–268. Ten samples per condition per process give 20 samples per version/condition. Each process interleaves the five engines randomly within each condition.
- Fresh fixtures and explicit GC occur before each timed public call. Construction, storage assertions, and result verification are outside the timer. data.table uses one thread. The allocation profiler is off. No allocation estimate is duplicated across timing observations.
- Every one of the 2,400 timed calls passed checks for complete values, column names/order, untouched attributes, target storage, and dplyr input isolation. Timed GC occurred in 211 main calls and zero candidate calls; those observations remain included in the medians.
- This matrix covers creation and arithmetic replacement, three shapes, and both requested input storage modes. It does not establish results for every expression, row selection, multiple-output operation, machine, or dependency version.

## Validation and compatibility

The full installed R suite passed 1,526 blocks across 107 files, with 26,834 assertions, zero failures/errors/skips, and seven existing warnings. After correcting the compiler namespace import and making compact-arithmetic success checks independent of test-file order, the final installed targeted run passed another 1,079 assertions without failures, skips or warnings. [Full observations](results-2026-09-29/validation/performance-tests.csv) and [final targeted observations](results-2026-09-29/validation/performance-final-targeted.csv) are included.

`R CMD build`, archive-content validation, and `R CMD check --no-manual --no-tests` completed. The check has the same three warnings and two notes as main: the local macOS deployment target for vendored objects, vendored GNU makefiles, a Rust abort symbol, vendored CITATION placement, and a generated C file without a final newline. The separate installed suite supplies test execution. [Check log](results-2026-09-29/validation/R-CMD-check.log).

The native manifest includes every current test file and preserves existing policies. The finite-certificate positive test explicitly permits a skip when its independent execution-profile oracle reports an unsupported runtime. Public results, errors, metadata, isolation, function replacement/tracing, and ordinary value-mutating callbacks remain covered. Direct mutation of compiled bytecode and modification of private package helpers/native registrations are outside the previously agreed compatibility boundary.

## Reproduce

Install main and candidate into separate libraries, then run from the repository root:

```sh
Rscript benchmarks/r-numeric-performance/compare-public.R /path/to/main-lib main /tmp/main-a 10 265
Rscript benchmarks/r-numeric-performance/compare-public.R /path/to/candidate-lib candidate /tmp/candidate-a 10 266
Rscript benchmarks/r-numeric-performance/compare-public.R /path/to/candidate-lib candidate /tmp/candidate-b 10 267
Rscript benchmarks/r-numeric-performance/compare-public.R /path/to/main-lib main /tmp/main-b 10 268
python3 benchmarks/r-numeric-performance/summarize.py /tmp/summary /tmp/main-a /tmp/candidate-a /tmp/candidate-b /tmp/main-b
```
