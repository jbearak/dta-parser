# Locate retained uniform chunks directly

Each retained scalar/span request previously binary-searched immutable chunk endpoints. The measured seven-/eleven-row stress fixture made 441,560 region calls and about 8.17 million partition comparisons per million-row pair. The candidate records a private uniform row stride when an owner is constructed and locates its chunk by integer division. Irregular owners keep the existing search; each lookup still obtains the pointer and extent from the selected actual chunk. Uniform row counts never imply contiguous buffers.

The owner fact is immutable and internal to Rust. Raw-owner construction proves regularity by construction; Arrow-owner preparation derives it during the existing chunk loop, allowing a shorter last nonempty chunk. No extra validation pass, mutable cursor, shared lookup cache or C ABI change is introduced. Empty and irregular owners use the conservative representation. One usize of owner metadata is added; payload widths and buffer ownership are unchanged.

The accepted six-round screen improves the four synthetic short-chunk cases 4.750–4.861× in median CPU (paired 4.789–4.878×), reaching 2.331–2.377 ms per million rows. Wall speedups are 4.749–4.848×. These cases still cost 7.179–7.337× the plain typed-double control. Their paired typed-normalized costs are 0.200–0.211, with no slower normalized round out of six. This is a substantial reduction of demonstrated lookup work, not ordinary-double parity or a file-reader throughput result.

Plain controls range 0.982–1.056× in median CPU; realistic retained 8191/16385-row controls range 0.960–1.016× and include several small costs. The largest paired typed-normalized cost is retained reverse-order random-half-missing addition, +4.57%, slower in four of six rounds. No general control improvement or universal no-regression claim is made; the cause of these small control shifts is not established.

Only owned_numeric.rs changes. The unchanged 116-case no-clock qualification and 696 timed observations cover both operand orders, all declared layouts/patterns, typed-double controls and bare controls only for missing-free cases. Controls remain plain in retained panels. Public operation allocation and automatic GC are timed; construction, reading, calibration, explicit GC, hashing and exact missing-cache mutation checks are outside recorded intervals.

The real Rust structural gate retains 11,367 API correctness checks over regular/irregular, shuffled/sliced buffers, short tails and descriptor-versus-owner bounds. Ten search-work failures on the baseline become zero on the candidate. Twelve Rust geometry traces join all 18 ordinary/sparse C traces without changing any requested/returned span. The explicit selected rustc and C trace receipt/CSV are bound before and after; source and tool inventories are preserved. This is untimed work evidence, not an instruction count or cancellation-latency measurement. Receipt-bound installed-library disassembly separately confirms the direct-division branch. Existing owner unit tests pass.
