# DTA writer qualification and corpus benchmark

Run date: 2026-08-28.

The source of record for the runtime provenance is `run-binding.tsv` in the
retained private bundle. It records R 4.6.1 on
`aarch64-apple-darwin25.4.0` and exact hashes for R, Rscript,
`/usr/bin/time`, Haven, processx, and Stata. Build output identified dtaparser
0.6.0 compiled with Rust 1.98.0, and the run setup selected the local Stata/MP
18 installation. The Rust and Stata version labels come from the build and run
setup; the binding independently fixes the exact Stata executable by SHA-256.

This report is aggregate-only: it publishes no private corpus paths,
filenames, stable per-file identifiers, labels, values, or raw rows.

## Qualification

This evidence covers a hash-bound local cache inventory; it is not an
upstream-authoritative corpus manifest. The inventory contained 1,823 DTA
files. All 1,821 files readable by the existing parser passed semantic
read-write-read comparison, Haven dimension comparison, and a Stata/MP 18
open-and-dimension check. The two previously recorded, SHA-256-bound unreadable
MICS inputs remained the only exclusions. A generated 32,768-variable file
also passed and exercised release 119.

| Corpus | Passed | Expected exclusions |
| --- | ---: | ---: |
| DHS | 643 | 0 |
| MICS | 949 | 2 |
| NSFG | 229 | 0 |
| Total | 1,821 | 2 |

The complete gate therefore finished with 1,821 passes, two expected
exclusions, zero failures, and `synthetic_wide = pass`.

## Executable interoperability scope

Stata/MP 18 performed every executable open-and-dimension check, including the
release-119 wide-file check. The Stata 18 writer target is restricted to
release 118; the Stata 19 target uses release 118 through 32,767 variables and
release 119 for wider datasets.

A separate executable run under Stata 19 was intentionally descoped because
this host has only Stata/MP 18. This report therefore records the complete
Stata/MP 18 qualification and does not claim an independent Stata 19
executable run.

## Corpus benchmark

After qualification, the same installed package and inventory completed 1,822
dtaparser writes and 1,822 Stata writes: the 1,821 qualified inputs plus the
wide release-119 case. Each input was measured once in a fresh process, with
writer order alternating across inputs.

Elapsed time covers only `write_dta()` or Stata's `save`, after the input was
loaded. Peak RSS covers the complete process, including its in-memory input.
