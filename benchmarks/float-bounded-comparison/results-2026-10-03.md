# Bounded compact-float comparison, 2026-10-03

Bounding the exact-decoding fallback makes a million-row plain compact-float pair
comparison 3.17 to 3.24 times faster when only the first 256 rows contain
missing values. Inputs with a missing first half improve by 1.49 to 1.57 times.
The change prevents a short exceptional prefix from selecting the slower loop
for an arbitrarily long ordinary tail.

These are direct comparisons of baseline
`bb135c1f274e0ddb5d37d29fdccdcf34b09f83f2` and candidate
`847919ceb78bf08674fca9f9af02583449e590a6`, using 768 observations. Earlier
comparison speedups are not multiplied into these results. Both builds already
contain the bounded decoded-double kernel, which is unchanged here.
The measured controller and its helper versions are committed at
`7671dfff9f42ddd22c2051254479ceed29ab8cf9`.

The large prefix improvement also appears in paired-round ratios, 3.233 to
3.255 times CPU, and wall-time ratios, 3.162 to 3.246 times. Clustered-half
paired CPU gains are 1.478 to 1.538 times. The retained prefix case stays near
one because its short spans already limited the old policy's reach.

The smaller regressions remain in the report. Retained clustered-half equality
uses 1.042 times the baseline CPU, with a 0.955 paired speedup. Plain suffix
`<` has a 0.956 speedup, with a 0.983 paired ratio. Plain all-tag equality has
a 0.962 median speedup, but a 0.997 paired ratio. Unchanged typed-double
controls range from 0.935 to 1.047 times speedup, with paired ratios from
0.960 to 1.039. These observations do not establish a cause for each small
difference or support a claim that every workload is faster.

All measured candidate compact cases use less CPU than their typed-double
controls. That is a scoped result for these constructed inputs, not a claim
about arbitrary imports or all compact operations. Bare R missing comparisons
propagate NA and do not implement the same tagged-missing ordering.

## Why the policy changes

The existing float kernel proves 64-row blocks ordinary by reducing the maximum
absolute binary32 bit pattern. Values below Stata's missing threshold take a
direct comparison loop. Other blocks retain exact modern or legacy missing
classification, permissive observed values, and unsupported-NaN validation.

Previously, four consecutive failed proofs selected the exact loop for the
rest of the captured span. Retained Arrow buffers usually split the work into
short spans, but constructed compact columns can pass their entire contiguous
buffer. A 256-row missing prefix could therefore force exact classification
of a million-row column.

The new policy decodes the current failed block once, processes at most 16,384
additional rows exactly, then resumes ordinary proofs. Each row still receives
the required validation, and an unsupported NaN keeps the complete native call
invalid even after proofs resume. The window is a work policy, not a cached
claim about the column's domain. Scalar comparison, missing classification,
retained-buffer ownership and output publication are unchanged.

A test-only counter at the actual exact-loop entry made the structural problem
reproducible. The [red test](results-2026-10-03/validation/red.log) counted all
1,000,000 rows after the 256-row missing prefix. The fixed test checks that
fewer than 10% take the exact path and verifies every output value. It avoids
a timing assertion and does not require an exact implementation-specific count.
The counter is absent from production builds. Boundary coverage exercises all
six operators, all modern/legacy format pairs, and invalid values before and
after the 16,640 and 33,280-row policy transitions.

## Measurement contract

The density, placement and ordinary panels contain 288, 288 and 192 observations.
Each uses one million rows, two operations, two storage layouts and compact or
typed-double representations. Typed doubles are contiguous in both layout
contexts and provide unchanged-runtime controls. Six rounds alternate build,
operation, layout and representation order in fresh R processes. Each
three-pattern panel uses all six pattern permutations; the two-pattern panel
uses each order three times. This does not claim every permutation of all
eight patterns.

Random-half operands have independent missing positions. The other dense
patterns align the missing positions in both operands. Alternating blocks
contain 500,032 missing rows because the million-row column has an odd number
of 64-row blocks. Sparse grids contain 1,003 and 1,010 missing values, with
2,011 rows missing in either input. All 27 canonical missing ranks cycle in
opposite order between operands. Finite input values are exactly representable
in binary32. Cross-pattern ratios do not isolate branch prediction.

The workers check every result against an independent integer-rank oracle.
Complete value, rank and result hashes, plus missing counts, agree across
builds, rounds, representations and equivalent layouts. Metadata hashes stay
unchanged for each case across builds and rounds; metadata need not match
between different representations. Native ownership and retained chunk counts
are checked separately from compact/materialized state before and after each
observation. Native eligibility is checked outside timing; it is not a
per-timed-call entry counter.

Repeated public calls include result allocation and automatic garbage
collection. Input construction, explicit collection, calibration, hashes and
native checks are excluded. Actual CPU intervals range from 207 to 354 ms.
The benchmark ran on one arm64 macOS host with R 4.6.1 while other local tests,
builds and benchmarks were paused. Normal desktop activity remained possible.
These are warm constructed operations, not reader throughput, memory-usage
measurements, arbitrary chunk layouts or confidence intervals.

Before and after each panel, the controller binds the actual Rscript launcher
and R runtime, controller files, compiler receipt, immutable source inventory
and installed library. Qualification uses the same bindings and no clocks.
The independent audit recomputes every summary and paired ratio, checks all
worker/raw identities and re-verifies the current full source, library and
runtime inventories. Audit scripts retain their original local paths; the
published receipts and raw observations are the portable evidence.

## Validation and integration

Measured runtime `847919ce` passes 61 Rust tests, 3,060 focused R comparison
assertions and the full installed R suite's 54,684 assertions, with no failures,
errors or skips and seven existing warnings. All 128 untimed benchmark
observations pass. The maintained controller passes 13 protocol tests normally
and with Python assertions disabled. The source and exact red/green commands
are recorded in the [setup receipt](results-2026-10-03/validation/setup-record.json).

Integration with current main and required source-archive conformance remain
pending. These later checks will be recorded separately from the measured
runtime and will not change the historical timing bindings.
