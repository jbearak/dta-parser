# R output-container results, 2026-09-01

Warm-cache local run on macOS with R 4.6.1, data.table 1.18.2.1, and 100
iterations per workload:

| Workload | Shape | Tibble then `setDT()` | Direct data table |
| --- | ---: | ---: | ---: |
| Tall, narrow synthetic table | 1,000,000 x 10 | 11.84 ms | 0.04 ms |
| Short, wide synthetic table | 100 x 10,000 | 28.42 ms | 0.31 ms |
| Complete `wide_v118.dta` read | fixture | 4.32 ms | 2.21 ms |

The synthetic rows isolate container finalization and share the column vectors;
they do not include decoding. The DTA row includes the complete read. These
results justify avoiding an intermediate tibble, especially for wide tables,
but are not portable timing thresholds.
