# Compact-float reciprocal block proof

For the public operation `1.01 / x`, the compact-float producer uses 42% less CPU on the measured million-row ordinary grid and 53% less with sparse missing values. A 256-row missing prefix improves 2.450×. The accepted change removes repeated result classification and fit checks from blocks whose observed denominators already prove that the result is finite and fits the chosen storage.

Dense inputs remain a separate limitation. Random 50% missing values and all 27 missing tags show essentially unchanged throughput and still cost 2.14× and 2.05× the typed-double controls. This change does not establish parity for those cases.

## Measurement and results

The [audited screen](evidence/screen-v1/summary.csv) contains 216 observations, with nine size/input strata, compact-float and typed-double representations, two builds and six paired rounds. It ran on macOS arm64 with 16 logical CPUs and requested one worker. Each build/round used a fresh R process. Build order alternated; representation positions were balanced. The nine strata rotated and reversed, but their positions were not exactly balanced.

The operation uses the ordinary public size policy. The 1,024-row control takes the existing R fallback; every call at or above 2,048 rows enters the native scalar producer after a primer. There is no additional cutoff. Small-call results do not justify one.

Per-call microseconds are batch totals divided by iterations, not independently resolved single-call timers. [Raw observations](evidence/screen-v1/raw.csv) retain CPU, elapsed time, batch counts and semantic records.

Inputs use exactly representable float values on the original integer-modulus grid. The ordinary grid contains observed zeros, whose reciprocal becomes system missing under the existing arithmetic policy. Sparse positions use a 997-row grid. The dense random mask contains exactly half the rows; all-tags cycles all 27 Stata missing codes. The timed storage is plain modern compact float. Retained chunks, legacy imports and arbitrary IEEE encodings receive semantic coverage, not throughput claims in this screen.

## Why the loop is cheaper

A finite binary64 scalar divided by a nonzero float has a magnitude that decreases as the denominator magnitude grows. The producer searches the positive binary32 encoding grid for a conservative minimum denominator that makes both signed quotients valid and fit. Both `scalar / t` and `scalar / -t` are evaluated, so the proof does not assume symmetric directed rounding. The search is capped at `0x7effffff`, below the Stata missing range.

Each 64-row block then reduces the minimum and maximum denominator magnitudes. Zero remains in the minimum. A block is admitted only when every value is an ordinary observed finite value and the minimum meets the bound. Its writer performs the original binary64 division followed by the existing final narrowing. It does not substitute inverse multiplication or pre-round the scalar.

Exceptional blocks keep exact format-aware decoding, result validation, fit checks and missing counts. Four failed block proofs switch to the exact writer for the remainder of the captured span, at most 16,384 rows. The next span can try the proof again. Any necessary whole-column promotion recomputes from the original captured inputs. The existing read claims and rooted captures remain unchanged.

The [actual-header work-count probes](evidence/structural/) separate this mechanism from timing. The baseline has zero semantic errors across 1,484 cases and fails 12 intended work gates. The candidate passes all semantic and work gates. On the million-row ordinary grid, exact per-result work falls from 1,000,000 rows to 6,400; sparse missing values require 70,080 exact rows. The new proof reduction still visits all rows, and the counters include its threshold predicates and both divisions. The reduction has not merely moved to an uncounted helper.

Release `-O2` inspection of this compiler and the installed candidate confirms that the threshold search retains both signed binary64 divisions and that the block reduction and ordinary writer vectorize. A separate replay with release flags passes the four rounding-mode witnesses and full semantic matrix. These observations are compiler-specific; equivalence of floating-point exception-flag traces is not claimed.
