# Compact float domain qualification

The strict and unknown directories contain the exact corrected benchmark
controllers. They compare immutable 213ceeee and 19f57372 source builds. Supply
clean build directories and the repository root, run --qualify-only first, then
supply that completed --qualification directory for six balanced rounds. The
unknown panel also requires --fixtures produced by its prepare.R worker using
the baseline library. See the recorded protocols for the complete matrices.

The current-source work-count.py drives copied actual production headers and
checks 162 semantic/work cases. Run it with --require-proved and a fresh
--output directory. It defaults to the repository HEAD, verifies consumed files
against immutable Git blobs, and requires a C compiler. The mock initializes
all domain facts UNKNOWN and grants the strict fact only after independently
validating each fixture. Ordinary, sparse, prefix and suffix workloads bound
canonical exception rows; generic float classification remains zero for trusted
fixtures. Imports, legacy values, IEEE exceptions and all-missing output retain
separate gates. R allocation, span and interrupt boundaries are mocked, so this
probe does not establish ownership safety or elapsed-time performance.

Public lifetime and mutation behavior is checked by the package tests. Timing
results and historical scripts belong in the dated evidence report. Redacted
historical scripts may require path and literal restoration and are not the
maintained commands in this directory.
