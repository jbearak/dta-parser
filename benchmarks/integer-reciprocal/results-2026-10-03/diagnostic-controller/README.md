# Private integer reciprocal diagnostic

This is a matrix-only adaptation of the reviewed general arithmetic worker/controller, using the same public calls, input formulas, value/storage oracle, repeated intervals, source-state checks and runtime/build verification. It does not change package code. It compares exact combined baseline `7003eba901671797ee91fffc97f08e28a1f7f515` against `3a02e6d13309441366a7a727fdc934f424ce66c6`. Both real build receipts retain variant `baseline`; logical experiment roles are separate.

Twelve cases cross each selected operation with no missing values and the original sparse missing grid. Four treatments are int16 and long `1.01 / x`. Eight unchanged controls are float `1.01 / x`, int16/float `x * 1.01`, and int16 `x * 2`. Three representations, two builds and six rounds produce 432 observations; the worker produces 36 untimed qualification records per build.

Both integer widths use `as.double((seq_len(1000000) * 13) %% 10001 - 5000)` as denominator values. Long is explicitly constructed with `dta_long`; it does not divide the grid by eight. Float controls divide the same grid by eight. Sparse input sets rows 13, 1010, ..., at stride 997, to system missing. The grid includes observed zero denominators, which become system missing in native typed arithmetic and retain ordinary R division behavior in bare controls under the existing separate oracle. Long reciprocal preserves the existing double-output rule; int16 output follows the unchanged promotion/float-rounding oracle. This is not a dense-missing, retained-chunk, or full signed-long-domain throughput test.

Both builds must enter native arithmetic on every typed call, in the untimed worker check and recorded timed counters. Bare calls must record zero entries. Full input/result/missing hashes, storage, anyNA cache behavior and unmaterialized-source state checks remain required. Outside clocks and native-entry accounting, every typed result is retained while a dibble alias clears all oracle-missing rows through `replace_values`. The worker compares all cleared result bits, requires `anyNA(FALSE)`, and rechecks the original result and input hashes/states. Empty missing masks still receive full-result and `anyNA` checks. Each row records the mutation check and cleared hash, which the controller requires and compares across builds/rounds. Bare ordinary controls have no native cached count and retain their independent Inf/NaN value oracle. Warmup/calibration/explicit GC and hashing are outside retained intervals; allocation and automatic GC remain inside. Calibration uses the original 25 ms minimum and 150 ms target, with all observed interval lengths retained.

Build order alternates by round. Case order is fixed. The original rotate/reverse worker formula covers all six representation orders; the controller retains its position-balance guard. The exact absolute Rscript launcher/runtime/version and original full build receipts, source/installed inventories and controller hashes are checked before and after. The recorder remains the source-bound maintained file in the frozen combined 7003 checkout, recorded by its own hash. Paths are private historical dependencies, not a portable published entry point.
