dtatools, datakit and dtaparser @VERSION@

An R package repository for dta-parser's R packages. It holds binaries for macOS (arm64), Windows (x86_64) and Ubuntu 24.04 (x86_64) for the current and previous R releases, and the source packages; dtaparser's need Rust to build. Installing dtatools installs the other two; for R's rules without dibbles, install c("dtaparser", "datakit") the same way.

macOS and Windows

install.packages("dtatools", repos = c("https://jbearak.github.io/dta-parser", "https://cloud.r-project.org"))

Ubuntu 24.04

install.packages("dtatools", repos = c(
  sprintf("https://jbearak.github.io/dta-parser/bin/linux/noble-x86_64/%s", getRversion()[, 1:2]),
  "https://cloud.r-project.org"
))

Documentation: docs/r.md.
